# layout-studio

射出成形の工場で、建物の中に成形機と周辺設備をどう置くかを手早く検討する図面エディタ。ブラウザだけで動き、スマホでも使える。

- 建物の図面（画像）を背景に置き、縮尺を合わせて、その上に設備を置いて動かす
- 設備は成形機・取出機・型抜き機・トリミング機・重量計・台車ストッカー（予備つき）
- 重なり・保守用の余白への入り込み・敷地からのはみ出しを色で知らせる
- AGV の通路（一方通行も）と工程のつなぎを描き、成形品が溜まって AGV が運び出す流れを再生する
- 案を複数持ち、敷地と外接の面積・床面積を表で比べる
- 図面を PNG 画像で保存する（白黒の表示にも切り替えられる）
- 手元の AI（Claude Code など）から MCP で配置を動かす

変わったことは [CHANGELOG.md](CHANGELOG.md)、これからのことは [ROADMAP.md](ROADMAP.md) にある。

## 開く

https://shostako.github.io/layout-studio/

インストールは要らない。PC でもスマホでも、ブラウザで開けばそのまま使える。`main` に変更が入るたびに自動で新しくなる（スマホで古い画面が出たら再読み込みする）。

作った配置はそのブラウザの中にだけ保存され（自動保存）、外へは送らない。別の PC やスマホに持っていくときは「保存」で JSON に書き出し、向こうの「開く」で読む。

## 使い方

道具バー（上の段）:

| ボタン | すること |
| --- | --- |
| パネル | 左の欄（狭い画面では下の欄）を出し入れする |
| 開く・保存 | 案を JSON ファイルから読む・書き出す（すべての案を 1 つのファイルに） |
| 例を開く | 成形機 7 台・14 台の例の配置（各 4 案）を案として足す |
| 画像 | 開いている案の図面を PNG で保存する（色はライト、左下に案の名前と縮尺） |
| ＋・－・全体 | 拡大・縮小・図面の全体を表示 |
| 元に戻す・やり直す | Ctrl+Z・Ctrl+Y と同じ |
| スナップ | 設備を置く・動かすときに合わせるグリッドの間隔 |
| 白黒 | 設備・通路・敷地を白黒の線で描く（正式な図面の見え方。画像も白黒になる） |
| 表示 | 色の見え方を 自動（OS の設定）・ライト・ダーク で切り替える |

左の欄（パネル）では、案の切り替えと比べる表、背景の図面と縮尺合わせ、敷地、AGV の通路、ひな形（設備を置く）、選択中の設備の寸法・色・余白、重なりの一覧、工程のつなぎ、流れの再生（サイクル・ストッカーの容量・AGV の速さと台数）、AI とのつなぎがある。

### PC（マウス）

- ひな形のボタンを押してから図面をクリックすると置ける。R で回す、Esc でやめる。
- 設備はクリックで選び、ドラッグで動かす。Shift+クリックで選び足す。Delete で消す、Ctrl+D で複製。
- ホイールで拡大縮小。中・右ボタンのドラッグか、Space を押しながら左ボタンのドラッグで画面を動かす。

### スマホ（指）

- 2 本指で拡大縮小と移動。
- 1 本指で何も無い所を引くと画面が動く。触って離すと選ぶ（置く・点を拾うも同じ）。
- 選んでいる設備・通路は、引くと動く。選んでいないものは引いても動かない（眺めているだけで配置がずれないように）。
- 図面の下に、キーの代わりのボタン（複数選ぶ・消す・回す・1 つ戻す・終える・やめる）が出る。
- 欄は図面の下に出る。「パネル」で出し入れする。

## 手元で動かす（開発する人向け）

Node.js 22.12 以上が要る（使っている Vite と Vitest が 22.12 より前では動かない）。`node -v` で確かめる。

```
npm ci              # 使うライブラリを入れる（最初の 1 回と、package-lock.json が変わったとき）
npm run dev         # 開発サーバー。http://localhost:5173 を開く。ファイルを直すとすぐ画面に出る
npm test            # テスト
npm run typecheck   # 型の検査
npm run build       # 配るものを dist/ に作る
npm run preview     # dist/ を http://localhost:4173 で開いて確かめる
bash scripts/ci.sh  # PR で走る検査をまとめて（型・テスト・ビルド・MCP サーバー）
```

`dist/` は相対パスで作るので、どこに置いても開ける。公開は GitHub Pages（`.github/workflows/pages.yml`。手順と中身は [docs/pages.md](docs/pages.md)）。

## AI から動かす（手元の MCP サーバー）

Claude Code など MCP に対応した AI から、開いている画面、または案の JSON ファイル（画面の「保存」で書き出したもの）を読み、配置の指示を確かめて当てられる。アプリは API キーを持たず、AI は利用者自身のものを使う。

```
npm ci
npm run build:mcp   # mcp/dist/server.js ができる
```

Claude Code に登録する（案のファイルを置くフォルダで。`/path/to/layout-studio` はこのリポを置いた場所）:

```
claude mcp add layout-studio -- node /path/to/layout-studio/mcp/dist/server.js
claude mcp list     # layout-studio: ... Connected と出れば使える
```

道具:

| 名前 | すること |
| --- | --- |
| `get_instructions` | 図面の決まり、指示の書き方、設備の種類と寸法を返す |
| `summarize` | 案の一覧と、1 つの案の要約（設備・通路・敷地・つなぎ・注意・次の id）と面積 |
| `check_commands` | 指示の列を当てたらどうなるかを確かめる（ファイルは変えない） |
| `apply_commands` | 確かめてから当て、ファイルに書き戻す。`new_plan` に名前を書くと、元の案を残して写しに当てる |

例: 「layout.json の案に、成形機を 3 台 2000 mm 間隔で縦に並べて取出機を載せ、新しい案『3台縦』にして」。1 つでも断られる指示があれば、どれも当てずにファイルもそのまま。書き換えたファイルは画面の「開く」で読み直す。

### 開いている画面にその場で当てる

1. 画面（`npm run dev` で開いた `http://localhost:5173` など）の左の欄、いちばん下の「AI とつなぐ（手元の MCP）」で「AI とつなぐ」を押す。
2. AI（Claude Code）を起動すると MCP サーバーも起動し、画面が「つながっています」になる（先に押しておけば、起動したときにつながる）。
3. AI に「画面の案に、成形機を 2 台…」のように頼む。道具の `file` を省くと画面の案を読み、当てた指示がその場で図面に出る。元に戻す（Ctrl+Z）1 回で全部戻る。

- MCP サーバーは `ws://127.0.0.1:47615` で待つ。番号を変えるときは `LAYOUT_STUDIO_PORT=…` を付けて登録し（`claude mcp add layout-studio -e LAYOUT_STUDIO_PORT=47700 -- node …`）、画面の「ポート」にも同じ番号を書く。
- つなげるのは手元（localhost・127.0.0.1）で開いたページだけ。ほかの場所に置いた画面からつなぐときは `LAYOUT_STUDIO_ORIGINS=https://…`（, 区切り）で足す。公開版（`https://shostako.github.io`）を足すこともできるが、https のページから手元の `ws://` へのつなぎを止めるブラウザもあるので、確実なのは `npm run dev` の画面。
- つなぐ画面は 1 つ。別のタブで押すと、前のタブは切れる。
