# 適切な配置の決まり（射出成形の組）

アプリはいろいろな設備を置ける汎用の作りを目指していて、設備の種類と配置の決まりは「組（プリセット）」ごとに持つ（DECISIONS.md 2026-10-14）。このファイルは射出成形の組の決まり。ほかの組を作るときは、同じ見出しで別のファイルを書く。

「付帯設備を適切に配置して」「適切な配置にして」と頼まれたときに、AI（どのセッションの Claude Code でも）とアプリの「付帯設備を付ける」「整える」が従う決まり。決まりを変えるときはこのファイルを直し、`src/core/aiPrompt.ts` の「配置のこつ」と、付ける・整える計算（作ったら `src/core/` に置く）も合わせる。

寸法はどれもひな形の値（架空の目安。`src/core/templates.ts`）。実際の案件で違うときは、設備ごとの寸法・余白を変えてから頼む。

## 基準は成形機

- 配置の基準は成形機。成形機の位置と向き（縦・横）はショスタコが決める。AI と「整える」は成形機を動かさない（頼まれたときを除く）。
- 横: 成形機の長い辺が図面の左右（x）に沿う。縦: 上下（y）に沿う。

## 取り出し側と並べる向き

取り出し側は、成形機の 2 つの長い辺のどちらに成形品を落とすか。並べる向きは、後工程（型抜き機から先）を長い辺に沿ってどちらへ並べていくか（例の配置の「取り出し左・右」）。どちらもシーンには項目として持たず、次の順で決める。

取り出し側:

1. 「付ける」に渡されれば、それに従う（画面では選ぶ。AI の指示では `side`）。横の成形機は上・下、縦は左・右。
2. 渡されなければ、その成形機につないだ取出機が張り出している側。
3. 取出機が無ければ、その成形機のユニットの付帯設備（型抜き機から先）がある側。
4. どれも無ければ、横は下（y の大きい側）、縦は右（x の大きい側）。

並べる向き:

1. 渡されれば、それに従う（AI の指示では `toward`）。横の成形機は左・右、縦は上・下。
2. 渡されなければ、つないだ取出機と反対の側（取出機が成形機の中心より右にあれば左へ）。
3. 取出機が無ければ、付帯設備がある側。
4. どれも無ければ、横は左（x の小さい側）、縦は上（y の小さい側）。

「整える」は渡さずに決めるので、今の取出機・付帯設備がある側と向きを保つ（2・3 で決まる）。

## 付帯設備（成形機 1 台ぶんのユニット）
## 付帯設備（成形機 1 台ぶんのユニット）

成形機 1 台に、次をつないで 1 つのユニットにする（工程のつなぎの順）。

1. 取出機: 成形機の上に載せる（重ねて置く。つないだ組の重なりは注意にしない）。梁は成形機の長い辺を横切る向きにし、取り出し側と反対へ 800 mm、残り（ひな形では 2800 mm）を取り出し側へ張り出す。長い辺に沿っては、成形機の中心から長さの 0.15 倍（ひな形では 1500 mm）だけ、並べる向きと反対へずらす（型の位置の目安）。
2. 型抜き機・トリミング機・台車ストッカー・予備: 取り出し側の長い辺に沿って、取出機の並べる向きの端から余白をあけて、並べる向きへこの順に並べる。列の線は、成形機の取り出し側の辺から余白の大きい方（ひな形では 1000 mm）離し、いちばん奥行のある設備の中心に揃える。つなぎは 取出機 → 型抜き機 → トリミング機 と、トリミング機からストッカーと予備へ 1 本ずつ（並列の枝。ストッカーから予備へはつながない）。重量計は使わない（2026-10-14）。
3. ストッカーと予備は列の端に並べ、AGV の通路に面させる（通路の中心線から近い所に乗り場が来るように）。

## 間隔

- 本体どうしの間は、両方の余白の大きい方（ひな形では付帯設備どうし 500 mm、成形機のまわり 1000 mm）。それより詰めると余白への入り込みの注意が出る。
- 本体と通路の帯（中心線から幅の半分）も重ねない。他の設備の本体を余白に入れない。
- 「整える」は、ショスタコが詰めた並びの順番と向きを保ったまま、上の間隔ちょうどに揃え、列の線（取り出し側の長い辺から一定の距離）に揃える。

## 敷地と通路

- 敷地の外形があれば、本体をその内に収める。
- 通路は AGV の幅（ひな形 1500 mm）。ストッカーの乗り場まで出入り口からつながっていること（再生の知らせが出ないこと）。
