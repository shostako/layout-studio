## 2026-10-13 立ち上げ

きっかけは、新規案件（極薄プレート）の見積もりで、成形機と周辺設備を建物の中にどう置くかを検討する必要が出たこと。

- 置きたい設備: 成形機、取出機、型抜き機、トリミング機、重量計、台車ストッカー。ストッカーは満杯になったら AGV が運び出す。切り替えのために予備のストッカーの置き場も要る。
- AGV の通路と搬出経路も図面に描きたい。
- 敷地はなるべく狭くしたい。詰めて面積を比べる道具にしたい。
- 生産中の流れ（成形品がストッカーに溜まり、切り替わり、運び出される）をアニメで見たい。
- AI に頼んで配置を動かせるようにもしたい。

名前は layout-studio にした（候補: plant-layout、shopfloor-studio、floor-flow ほか）。
方針は、TypeScript と Vite の Web アプリで、クラウドの Claude Code Projects に放置で進めさせる。
