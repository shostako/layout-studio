# 仕様

## 使う場面

新規案件の見積もりのために、工場の建物の中に設備をどう置くかを検討する。1人が画面で配置を動かし、面積と動線を見比べる。検討の途中の案を何本も残し、見比べられること。

## 設備の流れ

成形機 → 取出機 → 型抜き機 → トリミング機 → 重量計 → 台車ストッカー → AGV が搬出。

- 重量計で合格したものだけがストッカーに入る。
- ストッカーには決まった枚数が溜まる。満杯になったら AGV が搬出する。
- 切り替えの間も止めないよう、予備のストッカーの置き場が要る。
- 成形機は複数台あり、各台に取出機以降の列が付く。列を共有する案もある。

## 段階

### 第1段階: 置いて動かせる

- 背景の画像を読み込み、2点の距離を指定して縮尺を合わせる。
- 設備のブロックを置く。名前、幅×奥行（mm）、色を持つ。移動、回転（90度刻み）、複製、削除、グリッドへのスナップ。
- 設備の種類のひな形（成形機・取出機など）を、寸法を変えて使える。
- 画面の拡大縮小と移動。
- シーンを JSON で保存・読み込み。ブラウザの中にも自動で保存する。
- 元に戻す・やり直す。
- 敷地の外形（多角形）を描き、面積を出す。設備が外形からはみ出したら色で示す。

### 第2段階: 通路と干渉

- AGV の通路をポリラインで描く。幅を持つ。
- 設備どうし、設備と通路の重なりを検出して示す。設備ごとに保守用の余白を持たせ、余白との重なりも示す。
- 案を複数持ち、面積と余白の合計を並べて比べる。

### 第3段階: 流れのアニメ

- 設備を工程の順につなぐ。
- 成形品の発生、ストッカーに溜まる、満杯で予備に切り替わる、AGV が通路を通って運び出す、までを再生・一時停止できる。
- 成形のサイクル時間、ストッカーの容量、AGV の速度は数値で変えられる。

### 第4段階: AI で動かす

- 画面の操作と同じコマンドを、AI が出して配置を動かす。
- 「成形機を3台、この間隔で並べて」のような頼み方を受ける。
- Claude API のキーが要る。キーの扱いと費用は、この段階に入る前に決める。

## やらないこと

- 3D 表示。
- 建築図面（DXF や DWG）の直接の読み込み。背景は画像で足りる。
- 複数人での同時編集。
