# 防火壁がある前提の案を「台車を詰めて並べる」形に変えた版（2026-10-21）

[防火壁がある前提のレイアウト案](../20261021-防火壁/README.md)の保管場所の取り方を、台車を列にまとめて詰めて並べる形に替えた別の資料。成形機の並べ方と案の番号は元の資料のまま。元のフォルダは変えていない。

詰めた並べ方の前提と気になる点は [保管場所を詰めて並べる版の README](../20261021-保管場所-詰め/README.md) にまとめた（台車 1,200 × 1,100、隙間 100、通路 2,000 は列の両端だけ）。防火壁の帯（x 15.3〜16.2 m）と防火シャッターの前（両側 2.5 m・上下 0.5 m）に置かないこと、壁から 300 離すこと、東のシャッターの前を空けること、成形機からシャッターまでの道を空けることは元の資料と同じ。

- 平面図: `{台数}台_案{番号}.png` と `11台_参考_反操作側0.5m.png`（番号は元の資料と同じ）。本命の「列の両端に通路」を描いた。室内の図面を敷いた版は共有フォルダ（リポには入れない）。
- 一覧（29 案と参考 1 案）: [一覧.csv](一覧.csv)
- 作り方: [gen_wall_dense.py](gen_wall_dense.py)。`python3 gen_wall_dense.py` で PNG と CSV を作り直す（数分）。

## 結論

- 台車を 1,200 × 1,100 にすると、今の並べ方では元の資料より 15〜35 % 減る。詰めて並べると（両端に通路）、数え直した台数から 3〜137 % 増える。
- 何日分になるか（両端に通路）: 5 台で 13〜17 日、6 台で 9〜14 日、9 台で 2〜3 日、10 台で 1〜2 日。9 台以上は成形機で床がほぼ埋まり、詰めても 3 日分に届かない。
- おすすめは元の資料から変えない。元の資料は成形機まわりの占有で選び、保管は参考の数として載せている。詰めた並べ方でもその選び方は変わらない。おすすめの案の保管は次のとおり。

- 5・6 台で工場1 だけに成形機を置く案（5 台の案 1〜3、6 台の案 1・2・9）は、工場2 がまるごと空くので、詰めると大きく増える（+79〜115 %）。工場2 の床に南北の長い列（1 列 26 台）が並ぶ。
- 10 台で保管を重く見るなら [案 2](10台_案2.png)（占有 331.1 坪、両端に通路で 77 台・1.9 日分）。おすすめの案 1 より占有が 7.8 坪大きい。

## この資料で気になる点

- 工場2 に保管の列を置く案では、AGV は防火シャッターの開口を通って出し入れする。列の入口と出口が北と南の端に分かれると、北と南の 2 つの開口をそれぞれ一方向に使う形になる。開口の下で AGV が止まらないことと、火災のときの連動は元の資料と同じく要る。
- 9・10 台は保管の区画が壁ぎわの細い床に分かれ、列が短い（10 台の案 1・3 は 1 列 7 台まで）。区画ごとの出し入れの道が成形機の通路からの道と重なるので、保管を別の建物に持つ方が現実的かもしれない。
